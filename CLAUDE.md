# Mini Inventario

Aplicación web de inventario.

## Entorno
- Node.js 22
- Python 3.12

## Flujo de trabajo
- Cada cambio va en una rama nueva y se integra mediante pull request.

- Nunca subas llaves ni archivos `.env` al repositorio.

- Pide aprobación antes de borrar datos.
- Pide aprobación antes de desplegar.
